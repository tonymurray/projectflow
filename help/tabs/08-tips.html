Tips

Small things that are easy to miss.

Using the Templates folder in the Files launcher

Right-click empty space (not on a file) in the Files tab or the Folder Browser and choose New from Template to create a new file from your desktop's own Templates folder — whatever you've set up there (a blank text file, a starter spreadsheet, a custom snippet) shows up ready to use, pre-filled with a name based on the template, with no manual create-then-rename dance.

Pin more than just the viewer

The 📌 next to the viewer tab row pins both which viewer opens by default (Notes, Web, PDF…) and its content in one click. The Focus-layout launcher tab row has its own separate 📌 for pinning which of Docs/Resources/Files/Apps opens by default — worth doing both if you want a project to land exactly where you left it.

Zen mode for a distraction-free viewer

Ctrl+F11 collapses the launcher (and notepad, in Standard layout) so whatever you're viewing fills almost the whole window — handy for reading a long PDF or focusing on the code editor. It's independent of true fullscreen (F11), so you can combine both.

Watch for the alias name warning

If you create an alias launcher and the name you type already matches a real shell command (most importantly cd), ProjectFlow warns you before saving — aliasing over a builtin like cd silently breaks every later bare cd <dir> in the same shell. Renaming an alias you already made yourself (like ls) is fine and won't trigger it.

Search before you scroll

The search box above the launcher list filters live as you type, matching name, path, and application — searching npm surfaces every npm-handler launcher across every category, not just ones with "npm" in the display name.

Jump projects without scrolling

The ☰ button at the top-left of the title bar opens a full project switcher — pinned, recent, all projects, folder projects, and by-color, all searchable in one popup — without needing to scroll down to the Projects section.

Bootstrap Baloo tags in one click

Rather than tagging files by hand in Dolphin first, use "Create Baloo tags for all projects" (Settings → Integrations) or a single project's own "Tag files in this project…" (Project Settings → Integrations) to create the tag and populate Tagged Files immediately.
