Viewers

Everything you can look at or work in without leaving ProjectFlow.

The viewer tabs

A row of tabs across the top of the viewer column switches between:

  • Notes — this project's live markdown notepad (also always visible as its own column in Standard layout).
  • Editor — a built-in code editor (CodeMirror) for JS/Python/HTML/CSS/PHP/JSON and more, with find & replace, multi-cursor, folding, and syntax highlighting. Saves only on an explicit Save/Ctrl+S — never silently.
  • Terminal — a real embedded terminal (when the ttyd backend is available) or a Python/IPython console as a fallback.
  • Web — a full web browser view, also used to render local HTML and markdown files.
  • PDF and Image — built-in viewers with paging/zoom/fit controls.
  • ⏱ Time — appears once Kimai is configured (see Integrations).

Multiple tabs per viewer

Notes, Editor, Terminal, Web, PDF, and Image all support several open items at once as their own sub-tabs — open a second file without losing the first. Editor and Notes both remember unsaved changes and your cursor/scroll position when you switch away and back. Terminal tabs are the exception: each one is a genuinely separate running shell (capped at a handful at a time), so closing a terminal tab really does end that session.

Pinning a default

Click the 📌 button at the end of the viewer tab row to make whatever's currently showing (a specific PDF, a URL, a folder, …) the one this project opens to automatically next time. Each viewer's toolbar also has its own 📌 for pinning that specific piece of content independently of which tab is the default.

Focus layout differences

In Focus layout, clicking a launcher that would normally open an external app (a website, an image, a PDF, a local markdown/HTML file) instead opens it right there in the wide viewer column — the small preview icon next to such items flips to mean "open externally instead." The launcher column also gains its own Files tab: a compact file browser you can use to pop files straight into the viewer next to it, and an Apps tab: a curated grid of every real application this project's launchers reference.

The Folder Browser

Navigate the filesystem, see folders that already have a ProjectFlow config (marked [P]), and create new projects directly from a folder via Make Project. Right-click empty space for "New from Template" (using your desktop's own Templates folder), or right-click a file/folder for the usual open/rename/delete actions plus "Add to Project."
