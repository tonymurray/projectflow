Viewers

Everything you can look at or work in without leaving ProjectFlow.

The viewer tabs

A row of tabs across the top of the viewer column switches between:

  • Notes — Markdown notes can be viewed and edited here. Click and/or hover over text to edit and select formats. A project-specific note is always available.
  • Editor — a built-in text and code editor (CodeMirror) for JS/Python/HTML/CSS/PHP/JSON and more, with find & replace (Ctrl+F), syntax highlighting, go to line (Ctrl+G). Saves only on an explicit Save/Ctrl+S.
  • Terminal — a real embedded terminal (when the ttyd backend is available) or a Python/IPython console as a fallback.
  • Web — a full web browser view, also used to render local HTML and markdown files.
  • PDF and Image — built-in viewers with paging/zoom/fit controls.
  • ⏱ Time — appears when Kimai is configured (see Integrations).

Multiple tabs per viewer

Notes, Editor, Terminal, Web, PDF, and Image all support several open items at once as their own sub-tabs — open a second file without losing the first. Editor and Notes both remember unsaved changes and your cursor/scroll position when you switch away and back. Terminal tabs are the exception: each one is a genuinely separate running shell (capped at a handful at a time), so closing a terminal tab ends that session.

Pinning a default

Click the 📌 button at the end of the viewer tab row to make whatever's currently showing (a specific PDF, a URL, a folder, …) the one this project opens to automatically next time. Each viewer's toolbar also has its own 📌 for pinning that specific piece of content independently of which tab is the default.

3-Column layout differences

3-column layout is available in the project's settings, a legacy from early design. In this view the Notes viewer is always present and launchers default to external applications.

The Folder Browser

Navigate the filesystem, see folders that already have a ProjectFlow config (marked [P]), and create new projects directly from a folder via Make Project. Right-click empty space for "New from Template" (using your desktop's own Templates folder), or right-click a file/folder for the usual open/rename/delete actions plus "Add to Project.". If you a project default folder has not been assigned, you can asssign it in the file browser by clicking the 'double-home' button ⌂⌂.

Viewer Technologies reference

A reference for what actually renders each viewer in ProjectFlow.

Viewer Technology
ProjectFlow
(the app)		 Built with PyQt6, the Python bindings for the Qt6 application framework.
Notes Muya — the same live, WYSIWYG markdown editor engine used by the popular MarkText desktop app, embedded directly into the interface.
Editor CodeMirror 6 — a mature, widely used code-editing engine (the same family powers many web-based code editors), with built-in support for JavaScript, Python, HTML, CSS, and PHP.
Web Qt WebEngine — a module of the Qt framework (by The Qt Company), wrapping Google's open-source Chromium browser engine. The web engine is the basis for the Web/Notes/Editor/Help viewers
PDF Each page is rendered as a plain image using the Qt toolkit and displayed directly, along with a pager.
Image Handled natively by the Qt toolkit image display components — similar to PDF.
Terminal There are two modes: a quick command console for simple commands (the default), or a full real terminal for anything needing an interactive program like a text editor. The real terminal can be enabled in the settings.

The real terminal is powered by ttyd — a lightweight terminal hosted over localhost only (never reachable from outside your own machine), streamed to the page as a live web terminal. It runs with guardrails: bound strictly to localhost, origin-checked so only this app's own page can connect to it, and shut down automatically whenever ProjectFlow closes.
Settings Built directly with the Qt toolkit's standard interface components.
File browser Same as Settings — standard interface components only, re-uses desktop icons.
Time (⏱ Kimai) Standard interface components, communicating with the Kimai time-tracking service over the web via the Kimai API.
Help Uses the Web browser /QtWeb engine as above

Notes

  • Muya and CodeMirror are the two "real editors" in the app — genuine, full-featured editing engines running inside an embedded browser view, not simplified custom-built text boxes.
  • PDF and Image are the only viewers with no browser engine at all — just images rendered into ordinary display widgets. That lighter weight is also why each one can comfortably have several documents open in tabs at once, at almost no extra cost.
  • Web, Notes, and Editor each share a single embedded browser view, no matter how many tabs are open — switching tabs reuses that same view rather than opening a new one each time, which keeps things fast and light on memory.
