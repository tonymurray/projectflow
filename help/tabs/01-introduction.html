Welcome to ProjectFlow

A graphical launcher for organizing your desktop around projects — not folders, not apps, not browser bookmarks.

The problem

Real work rarely fits neatly inside one application. A single "project" — a website you're building, a business task like filing a tax return, a hobby like learning the guitar, a maintenance chore like backups — usually means juggling a folder of files, a handful of websites, a few terminal commands you always forget, some scattered notes, and maybe a PDF or two. That context lives nowhere in particular: spread across browser bookmarks, shell history, a random notes app, and memory.

The idea

ProjectFlow treats a project as the basic unit of organization, and gives each one a single place to keep everything that belongs to it: quick-launch shortcuts to files, folders, websites, and terminal commands; a live markdown notepad; and built-in viewers (PDF, image, web, code editor, terminal) so you often don't need to leave the app at all. Switching projects switches your entire context — shortcuts, notes, and whatever you were viewing — in one click.

This works for anything you'd call a "project" in the loosest sense: a software repo, a WordPress site, a backup routine, a piece of admin like a VAT return, a folder of research notes, even a hobby you're learning. If it has files, links, or commands you come back to, it can be a ProjectFlow project.

The three-panel layout

ProjectFlow's Standard layout has three columns, left to right:

  • Viewer — whatever you're currently looking at or working in: a web page, a PDF, an image, the code editor, a terminal, or your project notes.
  • Shortcuts — the launcher column: categorized buttons for every file, folder, URL, or command that belongs to this project.
  • Notepad — a live markdown editor, always visible, always this project's own notes.

There's also a Focus layout — a wider two-column view (Launchers | Viewer) better suited to documentation-heavy work, where Notes becomes one of several tabs in the viewer instead of its own permanent column. You can switch a project between the two any time from its Project Settings (see the Settings tab of this guide).
