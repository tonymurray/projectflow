Integrations

Third-party services ProjectFlow can talk to — all optional, all off until configured.

Kimai — time tracking

Configure your Kimai server URL and API token in Settings → Integrations to unlock a ⏱ Time viewer tab per project. Link a project to a Kimai project (via its own Project Settings) to see recent time entries, a period selector, a running total, and a quick "Log Time" form. If you generate CSV exports elsewhere (e.g. from a timesheet skill), point ProjectFlow at that folder and matching rows show up as "Pending Imports" ready to submit with one click.

Joplin — notes sync

Add a Joplin Web Clipper API token in Settings → Integrations to enable a manual sync button in the notepad toolbar, pushing this project's notes into Joplin.

Baloo — KDE file tags

On KDE, tag any file or folder in Dolphin with a project's name (its config filename — e.g. work.json → tag work) and it shows up automatically in that project's Tagged Files category — a way to pull in files that don't belong in any specific launcher category. Untag in Dolphin to remove it. Turn this on via the Enable Baloo Tags checkbox in Settings → Integrations.

Two buttons can create tags for you instead of tagging by hand in Dolphin:

  • Settings → Integrations → "Create Baloo tags for all projects" — tags every project's own notes file with that project's tag, in one sweep across your whole projects folder. Skips any project with no notes written yet.
  • Project Settings → Integrations → "Tag files in this project…" — a deeper, one-off sweep of just the project you have open: tags its notes file and every real file or folder any of its launcher items already points at.

Both show a results dialog listing exactly what got tagged (and skipped/failed) — not just a count — and never overwrite tags a file already has, only add to them.

Path mappings

If a project's files live at a different absolute path on this machine than where the config expects them (e.g. a synced folder mounted under a different name), add a From/To mapping in Settings → Advanced. It's applied only as a fallback when the direct path is missing — never silently preferred — and a small "⇄" badge marks anything shown via a mapping so it's obvious when you're not looking at the path actually saved in the config.
